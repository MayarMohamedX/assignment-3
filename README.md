# assignment-3
​A web development project featuring a validation form with instant error messages and a dynamic data table with real-time search and sorting using JavaScript.
​Project Description:
​A web development assignment built using HTML, CSS, and JavaScript, focusing on DOM manipulation, events, and form validation:

​1) validation.html (Registration Form): A user registration form with JavaScript validation that checks fields (name, email, password match, and age), displays instant error messages under invalid inputs, and prevents submission on failure.
​2) data.html (Data Table & Search): A dynamic data table generated from an array of JavaScript objects featuring real-time search filtering as the user types and sorting buttons for names and ages.
